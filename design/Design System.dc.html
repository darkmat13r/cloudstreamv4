CLOUDSTREAM 4 · DESIGN SYSTEM v0.1

Black shell, white focus, one red for live.

Every token here is lifted by role from the Live TV Guide / TV Player / Channels reference: its background became BG, its panel became SURFACE, its white selection outline became FOCUS, its progress line became LIVE. Nothing was invented to fill a slot. The rule that follows is the whole system in one line — chrome is achromatic, artwork carries all colour, and the single red appears only where something is playing or has been played.

01 · GRID & UNITS

Every dimension is a multiple of 4

Widths, heights, padding, gaps, radii, icon and target sizes, and type sizes all land on a 4px step. The only things off the step are 1px hairlines — stroke weights are not layout dimensions — and unitless line-heights. This document and every artboard in the project are built to it, and it matches the rule the repo already enforces in .claude/rules/dimension-scale.md.

{{ s.label }}

A 1920×1080 TV layout is 960×540 dp at xhdpi — every artboard pixel is half a dp. So a 4px artboard step is a 2dp step in Compose, and the 8px step is the one that maps to the repo’s 4dp rule. Size in artboard pixels, halve for Compose.

Correction carried into this system. The TV screens drafted before this document used 11–13px metadata on a 1920px artboard — that is 5.5–6.5 dp, roughly half Android TV’s readable floor, and off the 4px step besides. The type scale below sets the floor at 20px / 10 dp and every value is re-derived onto the grid.

03 · TYPE

Manrope for voice, JetBrains Mono for facts

Two families with one job each. Anything a human wrote — titles, synopses, labels — is Manrope. Anything a machine produced — resolution, codec, file size, latency, episode numbers, timestamps — is mono. That split is what makes the source panel scannable, and it is the closest thing this app has to a signature. Every size is a multiple of 4.

05 · FOCUS

The most important component is not a component

On a remote there is no cursor, so focus is the interface. It must be identifiable from across a room, in one glance, with no colour vision required — which is exactly why it is white and not the red. Three rules: focus is always a 4px white outline at 4px offset; it never relies on colour alone; and exactly one thing on screen has it.

Navigation is the one thing that genuinely differs. TV gets the collapsing left rail because D-pad travel is cheap vertically and expensive horizontally. Mobile gets a bottom bar because thumbs live at the bottom. Desktop gets a persistent expanded sidebar because there is width to spare and a pointer to aim with. Everything below the navigation — rails, cards, detail layout, the source panel — is the same system at three densities.
08 · STATES

Every surface owes five of them

An extension-driven app fails in ways Netflix never does: a provider goes down, a repo is unreachable, a source resolves to nothing. These are normal conditions, not edge cases, and the design has to name them rather than showing an empty rail.
