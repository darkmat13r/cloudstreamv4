REF Inspiration board — palettes read by role, not by area

Correction on the previous round. I was ranking colours by how much of the image they covered, which returns backgrounds and poster artwork and never the button — a primary button is roughly 0.1–1% of the pixels. That produced the claim that real streaming UI stays under 50% saturation, which is wrong; it was measuring blurred artwork averages, not UI fills. Reading by role instead — exact-RGB flat fills, since a button repeats one precise value over a contiguous area while photographic regions never do — the real primaries come back at 73–98% saturation. Animax’s Play button is #06C149, Online Cinema’s is #C1FD20, slothUI’s is #4F46E5, Reelmark’s Trailer button is #E70207. Each was cropped and checked by eye to confirm it is the button and not a coincidence. The real pattern is a near-neutral dark shell plus one loud primary used sparingly — so each direction below now takes BG / SURFACE / PRIMARY / INK from a single reference.
